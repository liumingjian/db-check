## 处理常见问题

| 现象 | 处理方法 |
| --- | --- |
| `未知参数: ...` | 检查参数拼写。执行 `{{COLLECTOR}} --help` 查看全部参数。 |
| `缺少 --db-password` 等以「缺少」开头的提示 | 在命令中补上提示中的参数。 |
| `--dbname 与 --oracle-service-name 互斥` | 删除其中一个参数。 |
| `--local 与 SSH 参数互斥` | 删除 `--local`，或删除所有 `--os-` 开头的 SSH 参数。 |
| 报告中有检查项标为「权限不足」 | 请客户 DBA 按报告末尾的说明补充只读授权，然后用相同的命令重新采集。 |

采集日志是结果目录中的 `collector.log`。向技术支持反馈问题时，附上这个文件。
