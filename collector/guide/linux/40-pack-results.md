## 把采集结果压缩成 ZIP

每次采集在 `runs` 目录下生成一个结果目录。目录名就是采集命令输出的 `run_id`，例如 `mysql-10.0.0.10-20261008T020304Z`。

进入 `runs` 目录，把本次的结果目录压缩成 ZIP。把下面两处 `mysql-10.0.0.10-20261008T020304Z` 换成你的 `run_id`：

```bash
cd runs
zip -r mysql-10.0.0.10-20261008T020304Z.zip mysql-10.0.0.10-20261008T020304Z
```

一个 ZIP 只能放一次采集的结果。如果主机上没有 `zip` 命令，把结果目录复制到其他电脑后再压缩。
